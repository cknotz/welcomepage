Velkommen!

Dette er en spørreundersøkelse for samfunnsvitenskapelig forskning. I undersøkelsen vil vi stille deg spørsmål om dine holdninger, dine oppfatninger og din bakgrunn. Ved å delta i denne undersøkelsen kan du bidra til vitenskapelig forskning og uttrykke din mening om viktige økonomiske og politiske spørsmål.

Undersøkelsen er helt anonym og frivillig. Vi samler ikke inn informasjon som kan identifisere deg, og du kan avslutte deltakelsen når som helst og av hvilken som helst grunn.

Vær obs: Vi gjennomfører kvalitetssjekker. Svar som virker veldig raske, tilfeldige eller useriøse kan bli utelatt.

Denne undersøkelsen gjennomføres av forskere ved Universitetet i Stavanger (UiS). Hvis du har spørsmål om undersøkelsen eller hvordan informasjonen din beskyttes, kan du kontakte prosjektlederen (carlo.knotz@uis.no).
